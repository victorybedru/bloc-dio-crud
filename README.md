# Quote Keeper - Flutter CRUD App 📝

A simple CRUD application built with Flutter, BLoC state management, and Dio for API calls.

## Features

- ✅ **Create** - Add new inspirational quotes
- ✅ **Read** - View all saved quotes
- ✅ **Update** - Edit existing quotes  
- ✅ **Delete** - Remove quotes you don't need
- ✅ Random quote generation from external API
- ✅ Loading states & error handling

## Tech Stack

- Flutter SDK
- BLoC/Cubit for state management
- Dio for HTTP requests
- Quote Garden API for random quotes
